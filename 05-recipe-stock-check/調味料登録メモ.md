# 常備調味料の登録メモ

レシピ照合を正しく動かすため、調味料も在庫シートに入れておく。
**一度やれば当分不要**（期限が長いので、通知にもしばらく出てこない）。

## やり方

冷蔵庫と棚を見て、**実物の期限を確認**しながら、LINE Bot に以下の形式で送る。
一度に何件でもまとめられる。

```
醤油は2027年3月31日、みりんは2027年8月31日、料理酒は2027年2月13日
```

音声入力でも同じように送れる。

## 注意

- **塩と砂糖は期限表示がない**ことが多い。その場合は `2030年12月31日` など遠い日付を入れておく
- 開封済みで期限が読めないものは、だいたいの目安で構わない。通知の精度が少し落ちるだけ
- 登録済みのものを再度送ると**重複確認**が出る。二重登録なら「登録しない」と答える

## 登録後の確認

LINE で `在庫` と送ると一覧が出る。抜けがないか確認する。
