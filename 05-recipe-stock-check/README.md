# 05. レシピ在庫チェック

レシピの材料と、LINE Botで管理している在庫を突き合わせて買い物リストを作る。

## 使い方

Claude Code に**レシピの写真を渡して**、こう言うだけ。

```
このレシピで買うものを教えて
```

画像を直接チャットに添付しても、`レシピ画像/` に置いてファイル名を伝えても動く。

## 出力

```
【麻婆豆腐】

■ 在庫あり（2件）
・鶏がらスープ    登録 9/6・期限 2028-06-05
・醤油            登録 8/1・期限 2027-03-31

⚠ 在庫ありだが要確認（1件）
・片栗粉          登録 9/6・期限 2026-06-09（89日超過）

■ 買うもの（3件）
・豚ひき肉（150g）
・長ねぎ（1本）
・豆腐（1丁）
```

**登録日を併記**しているのは、残量の目安にするため。3か月前に登録した醤油なら残り少ないかもしれない、といった判断ができる。

## 仕組み

```
レシピ画像 ──┐
             ├─→ Claude Code ─→ 買い物リスト
スプレッドシート「食材在庫」┘
（Google Drive 読み取り）
```

在庫データは LINE Bot（`04-food-expiry`）が書き込んだものを**読むだけ**。このスキルからスプレッドシートは変更しない。

## 制約

**数量は判定できない。** 在庫シートは1行＝1個で、残量を持っていない。

「牛乳200ml必要／在庫に牛乳1本」に対して足りるかどうかは分からないので、
「ある・ない」と登録日だけを示す。最終判断は自分でする前提。

## 前提：調味料を在庫登録しておく

醤油・塩・砂糖・油などを登録していないと、レシピのたびに「買うもの」に並んでしまう。
最初に一度、LINE Bot にまとめて送っておく。

→ [調味料の登録メモ](調味料登録メモ.md)
